# Bundled fonts

All bundled fonts use the SIL Open Font License 1.1. License files ship in the APK.

| Font | Source and license | Packaged notice |
| --- | --- | --- |
| Geist | [Vercel](https://github.com/vercel/geist-font) | `res/raw/geist_ofl.txt` |
| Alata | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/alata/OFL.txt) | `res/raw/alata_ofl.txt` |
| Atkinson Hyperlegible | [Google Fonts](https://github.com/google/fonts/blob/main/ofl/atkinsonhyperlegible/OFL.txt) | `res/raw/atkinson_ofl.txt` |
| IBM Plex Sans | [IBM](https://github.com/IBM/plex/blob/master/LICENSE.txt) | `res/raw/plex_ofl.txt` |

The font files also retain their copyright and license metadata. The bundled Alata files credit the 2019 Alata Project Authors; the bundled Plex files credit IBM Corp. in 2018.

System sans serif uses Android's font. Custom fonts stay in private app storage and are not bundled or uploaded.
